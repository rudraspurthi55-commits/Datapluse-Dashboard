# DataPulse — AI Retail Sales Analytics Dashboard

A multi-page analytics dashboard built with Python, Streamlit, Pandas, and Plotly.

## Features
- Sales trend analysis
- Product performance tracking  
- Interactive chart builder
- AI-powered insights

## Tech Stack
Python | Streamlit | Pandas | Plotly | Git

## How to Run
pip install -r requirements.txt
streamlit run Home.py
